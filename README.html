cadre_montage_v1.py — Refonte dessin de montage Cadre & Trapèze Python Refonte complète du module de dessin technique :
• Tubes en contour : montants dessinés en parallélogramme biseauté (trapèze) avec fond blanc + contour sombre, comme un vrai tube aluminium.
• Hypoténuse tube : rendue comme un tube (double ligne parallèle), pas une simple ligne.
• Spigots repositionnés : haut = jonction montant/traverse, bas = extrémités segments traverse.
• Cotations "point le plus long" : V.G. → _yt(0), V.D. → _yt(1), HYP → coin extérieur à coin extérieur = √(L²+(VG-VD)²).
• Cotation hypoténuse avec lignes d'attache : même style que V.G./V.D. — ligne décalée parallèle + lignes d'attache perpendiculaires + flèches aux bouts. Texte plus affiché sur le tube.
• Taille texte augmentée pour usage usine : titre 10pt, valeurs en-tête 10pt, cotations 8.5pt/7.5pt, légende 11pt/10pt. Règle documentée dans docstring (min 8pt partout).
